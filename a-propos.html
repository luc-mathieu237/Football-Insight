À propos du projet

Le problème

Les statistiques d’un joueur sont souvent dispersées dans des tableaux difficiles à lire. Ce site rassemble l’essentiel sur des pages claires, lisibles sur téléphone, pour qu’un supporter ou un recruteur comprenne en quelques secondes la progression d’un attaquant.

Pour qui ?

Pour les supporters, les recruteurs et les staffs qui veulent une vue rapide, sans jargon.

Les données

Toutes les statistiques sont fictives et ont été créées pour cet exercice. Elles sont écrites à la main dans le fichier js/data.js. Aucun service externe n’est utilisé : si l’on change une valeur dans ce fichier, tout le site se met à jour.

La méthode

Le contenu est structuré en HTML, mis en forme en CSS, puis rendu vivant par JavaScript (tableau, filtre, graphique). Le projet est versionné avec Git et publié avec GitHub Pages. Une maquette sur papier a précédé le code.

Les limites

Les données étant fictives, aucune conclusion sportive réelle ne peut en être tirée. Seules quatre saisons sont présentées, sans contexte sur les adversaires. Le schéma de terrain est illustratif.

Prochaines améliorations

Ajouter d’autres joueurs, comparer deux profils, proposer un mode sombre et enrichir les graphiques.
